# QtDesignerAngularLabelPlugin
*Qt label at any angle*

An HTML-capable implementation of Qt Label that can be rotated by an arbitrary angle, ideal for adding a bit of mess to the UI so it looks more cool.

_Usage_
1. Build and install the plugin in your Qt directory
2. Use AngularLabel.* files in your project
